谛听（Diting）· Android 本地录屏工具

一、项目简介

谛听（Diting）是一款面向 Android 的本地录屏工具，支持两种录制方式：

  • 基础录屏：基于系统 MediaProjection，免 Root、免 Shizuku，用户授权后即可录制。
  • 增强录屏：通过 Shizuku 以 shell 身份运行采集进程，可获得更强的系统声音捕获能力。

所有录制均在设备本地完成，不联网、不上传、不收集用户数据。详见应用内的《隐私政策》。

三、基于上游项目的修改声明

依据 Apache License 2.0 第 4(b) 条要求，本节声明本衍生作品相对于上游原始项目所做的修改。

本项目的部分底层录屏能力（私有显示接口采集、OpenGL 渲染管线、硬编码器封装、Shizuku/shell 运行框架等） 源自开源项目 ZeroRecorder，在此基础上进行了较大规模的二次开发与品牌重构。

主要修改内容

类别具体修改
品牌重构 应用名由 ZeroRecorder 改为「谛听」；包名由 com.zero.recorder 改为 com.diting.recorder；重新设计应用图标。
界面重做 重写全部界面为原生 Material 3 风格；新增设置体系（录制项 / 权限项 / 关于三层结构）、音频自检页、联系与隐私政策页；图标统一改用 Tabler Icons。
