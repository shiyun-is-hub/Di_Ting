Designed for control

把录屏交还给设备

谛听把录制过程尽可能留在本机。没有云端中转，也不把你的录制内容变成“服务数据”。

01 / LOCAL

本地完成

录制内容保存在你的 Android 设备上，默认输出到 Movies/Diting。

02 / FLEXIBLE

两种录制模式

基础录屏面向所有用户；增强录屏为 Shizuku / Root 用户提供更强的采集能力。

03 / PRECISE

参数可控

支持跟随屏幕、1080p、720p 等画质，以及 30fps / 60fps 帧率选择，并提供音频自检。

Two ways to record

从简单开始，也可以深入

根据设备能力与使用习惯选择录制方式，不把 Root 作为普通用户的入场券。

推荐 · 基础录屏

MediaProjection

使用 Android 系统标准录屏授权，免 Root、免 Shizuku。

  • Android 10（API 29）及以上
  • 系统标准“整个屏幕”授权
  • 系统声音取决于厂商 ROM 对 AudioPlaybackCapture 的支持
高级 · 增强录屏

Shizuku / Root

通过 shell 身份运行独立采集进程，获得更强的系统声音捕获能力。

  • Android 8.0（API 26）及以上
  • 需要 Shizuku 或设备已有 Root
  • 支持悬浮控制、录制状态、计时与一键停止
